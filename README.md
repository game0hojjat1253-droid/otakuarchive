# Otaku Archive v3

آرشیو شخصی انیمه، مانگا، فیلم و سریال؛ یک PWA قابل نصب روی گوشی (بدون بک‌اند، بدون نیاز به نصب چیزی).

- جست‌وجوی انیمه/مانگا از AniList (بدون کلید) و فیلم/سریال از TMDB (با توکن رایگان)
- افزودن دستی، ویرایش وضعیت/پیشرفت/امتیاز/یادداشت، دکمه سریع «+۱ قسمت»
- فیلتر، جست‌وجو و مرتب‌سازی کتابخانه، آمار، پشتیبان‌گیری JSON
- کار کردن آفلاین (حتی پوسترها)

## راه‌اندازی

### ساده‌ترین راه: GitHub Pages (برای نصب روی اندروید)
1. در GitHub یک repository بساز و همه فایل‌های این پوشه را آپلود کن.
2. Settings ← Pages ← Branch: `main` / root ← Save.
3. لینک `https://USERNAME.github.io/REPO/` را در Chrome اندروید باز کن ← منو ⋮ ← **Install app**.
   (در آیفون: Safari ← Share ← Add to Home Screen.)

### تست روی کامپیوتر
```
python3 -m http.server 8000
```
و بعد `http://localhost:8000` را باز کن. (با دابل‌کلیک روی `index.html` هم باز می‌شود، ولی نصب و حالت آفلاین فقط روی http(s) کار می‌کند.)

### فیلم و سریال (TMDB)
از themoviedb.org ← Settings ← API توکن بگیر و در **تنظیمات** برنامه وارد کن. هر دو نوع «API Read Access Token» و «API Key» قبول است. دکمه «تست اتصال» درستی را چک می‌کند.

## چه چیزهایی در v3 درست یا اضافه شد

**باگ‌ها**
- شناسه آثار TMDB موقع ذخیره عوض می‌شد؛ تشخیص «قبلاً اضافه شده» کار نمی‌کرد و فیلم و سریال با شناسه یکسان روی هم می‌افتادند. (داده‌های قبلی خودکار مهاجرت می‌شوند.)
- ثغره XSS: شناسه داخل فایل بکاپ بدون پاکسازی در HTML اجرا می‌شد.
- فایل بکاپ ناقص/خراب یا دیتای خراب localStorage کل برنامه را از کار می‌انداخت؛ حالا ایمن است و نسخه خراب جدا نگه داشته می‌شود.
- امتیاز/پیشرفت/آدرس پوستر در ایمپورت اعتبارسنجی نمی‌شد.
- سرویس‌ورکر قدیمی برای همیشه کش می‌کرد و هیچ‌وقت آپدیت نمی‌شد؛ آفلاین بودن هم کامل نبود.
- بدون آیکون، برنامه روی اندروید به‌عنوان PWA نصب نمی‌شد.
- دکمه برگشت گوشی برنامه را می‌بست؛ حالا بین صفحه‌ها برمی‌گردد.
- شکست در ذخیره (حافظه پر) بی‌صدا بود؛ حالا هشدار می‌دهد.
- رقابت درخواست‌ها هنگام تغییر سریع نوع جست‌وجو، و فونت ۱۴ پیکسلی ورودی‌ها که در آیفون زوم می‌کرد.
- بسته نشدن دیالوگ با لمس بیرون، و خطاهای مبهم شبکه/۴۲۹.

**قابلیت‌های جدید**
- دکمه «+۱ قسمت/چپتر» روی کارت‌ها (با امکان لغو) و بخش «در حال دنبال‌کردن» در خانه
- افزودن دستی اثر، تغییر نام و لینک پوستر
- تکمیل خودکار وضعیت وقتی به تعداد کل رسیدی؛ تعداد قسمت سریال‌های TMDB خودکار پر می‌شود
- «بازگردانی» بعد از حذف، بازیابی بکاپ و پاک‌کردن آرشیو
- بازیابی بکاپ با گزینه **ترکیب** (علاوه بر جایگزینی)، یادآوری پشتیبان، نام فایل با تاریخ
- مرتب‌سازی کتابخانه، جست‌وجو در نام‌های جایگزین و یادداشت‌ها، وضعیت «رهاشده»
- صفحه تنظیمات جدا، تست توکن، دکمه نصب برنامه، صفحه آمار کامل‌تر

## ذخیره‌سازی و همگام‌سازی
- داده‌ها در IndexedDB ذخیره می‌شوند (با نسخه‌های خودکار، محافظت از حذف گروهی و درخواست «ذخیره دائمی»).
- همگام‌سازی اختیاری با **Google Drive شخصی هر کاربر** (پوشه مخفی برنامه، مجوز `drive.appdata`) با تشخیص تعارض.
- راه‌اندازی کامل (Cloudflare Pages + Google OAuth): فایل **GUIDE-fa.md**. Client ID را در **config.js** بگذار.

## تب پیشنهاد
از آثاری که امتیاز ۷ به بالا داده‌ای و ژانرهای موردعلاقه‌ات، اثر جدید پیشنهاد می‌دهد: انیمه و مانگا از AniList، و فیلم و سریال از TMDB (فقط با توکن). نتیجه تا ۲۴ ساعت ذخیره می‌شود؛ با ✕ هر پیشنهاد را می‌توانی حذف کنی.

## منابع جست‌وجو
- تب **همه**: انیمه، مانگا، فیلم و سریال را با هم جست‌وجو می‌کند.
- انیمه/مانگا: AniList. فیلم/سریال: TMDB (اگر توکن داری)؛ در صورت نبودن توکن، نامعتبر بودن، محدودیت، قطعی یا نتیجه خالی، خودکار **TVmaze** (سریال) و **iTunes** (فیلم) استفاده می‌شود.
- برای لیست‌های بزرگ: کتابخانه ۴۰تا۴۰تا بارگذاری می‌شود، فقط صفحه باز ساخته می‌شود و ذخیره‌سازی با تأخیر کوتاه انجام می‌شود.

## نکته‌ها
- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند و همگام‌سازی ابری ندارند؛ با «خروجی JSON» گاهی پشتیبان بگیر. آرشیو را بین دو گوشی با همین فایل می‌توانی منتقل کنی.
- توکن TMDB روی همین دستگاه می‌ماند؛ آن را در کد منتشرشده نگذار. برای انتشار عمومی، بک‌اند/پراکسی و رعایت الزامات انتساب TMDB لازم است.
