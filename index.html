تنظیمات

جست‌وجوی فیلم و سریال (TMDB — اختیاری)

بدون توکن، سریال از TVmaze و فیلم از iTunes جست‌وجو می‌شود (اسم انگلیسی بنویس). اگر TMDB برایت باز می‌شود، یک توکن رایگان از themoviedb.org ← Settings ← API بگیر. هم «API Read Access Token» (رشته بلند) و هم «API Key» (۳۲ حرفی) قبول است. انیمه و مانگا بدون توکن کار می‌کنند.

پشتیبان‌گیری

اطلاعات فقط در همین مرورگر ذخیره می‌شود. پاک کردن اطلاعات مرورگر یا حذف برنامه، آرشیو را پاک می‌کند؛ پس گاهی خروجی بگیر.

نصب برنامه

در Chrome اندروید: منوی ⋮ ← Install app. در آیفون (Safari): دکمه Share ← Add to Home Screen.
